# Motyw Nieprzypadkowy Czytelnik

Katalog przeznaczony na pliki własnego motywu WordPress.

Pliki z tego katalogu będą wdrażane przez GitHub Actions wyłącznie do dedykowanego katalogu motywu w testowej instalacji WordPressa na OVH. Nie umieszczamy tu plików rdzenia WordPressa, konfiguracji, sekretów ani kopii bazy danych.

Właściwy motyw zostanie dodany po zatwierdzeniu projektu wizualnego.
