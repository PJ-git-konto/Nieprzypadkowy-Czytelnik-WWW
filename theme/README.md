# Motyw Nieprzypadkowy Czytelnik

Własny motyw WordPress wdrażany przez GitHub Actions do testowej instalacji OVH.

## Zawartość pierwszego etapu

- responsywny szkielet strony głównej;
- własny typ treści „Książki” z polem autora i obrazkiem wyróżniającym jako okładką;
- sekcja trzech losowych rekomendacji;
- endpoint REST i przycisk pobierający kolejny zestaw;
- podstawowa nawigacja i stopka.

## Ważne

To pierwszy techniczny szkielet, a nie końcowe odwzorowanie zaakceptowanej makiety. Nie dodano jeszcze właściwego logo ani zdjęć z makiety — należy wprowadzić oryginalne pliki źródłowe, a nie wycinać całego zrzutu strony na fragmenty. Wygląd i proporcje dopracowujemy po porównaniu podglądu z zaakceptowanym projektem.

Nie umieszczamy tu rdzenia WordPressa, sekretów, konfiguracji ani kopii bazy danych.
