# Nieprzypadkowy Czytelnik — WWW

Repozytorium zawiera pliki strony internetowej marki **Nieprzypadkowy Czytelnik**.

## Wdrożenie

Repozytorium jest przeznaczone do wdrożenia na hostingu OVH przez integrację Git. Katalog główny repozytorium jest katalogiem publikacji strony, dlatego plik wejściowy znajduje się w `index.php`.

## Struktura

- `index.php` — tymczasowa strona główna
- `assets/images/` — grafiki
- `assets/css/` — arkusze stylów
- `assets/js/` — skrypty JavaScript

**Hasło marki:** Dobre książki. Świadome wybory.
